# 데이터 기준 안내 / Data guide

가상 생산 데이터이며 실제 공장 시스템과 연결하지 않는다. 연결한 생성본의 기준 시각·조회 범위·식별값은 이 문서 마지막의 메타정보를 따른다.

- 시간대: Asia/Seoul. 생산일은 08:00~다음 날 08:00 직전. 주간 08~20시, 야간 20~다음 날 08시, A/B조가 교대한다.
- 상대 기간은 PC의 현재 시간이 아닌 데이터의 referenceNow로 해석한다. “지난주”는 직전 달력 주의 생산일, “최근 4주”는 완료된 생산일까지 28일, “4주 전”은 특정 달력 주다.
- period 예: {"kind":"last_month"}, {"kind":"recent","unit":"weeks","count":5}, {"kind":"week_day","weeksAgo":1,"weekday":3}, {"kind":"range","from":"2026-09-01","to":"2026-09-15"}.
- 요청 범위와 실제 생산일을 구분한다. 범위 밖 요청은 자동으로 잘라 조회하지 않고 out_of_range로 안내한다. 범위 안 휴무일만 선택하면 non_working_day다.
- 라인을 생략하면 전체 라인. 생산량은 기본 produced, 달성률은 good/target. 생산량 총합만으로 제품이 다른 라인의 효율 순위를 매기지 않는다.
- 미입력은 0이 아니다. missing_data와 coverage를 확인한다. 비교 기간 어느 쪽이든 누락이 있으면 비교도 불완전하다.
- 상세 목록은 응답당 각 배열 최대 60개다. 합계는 전체 조회 대상 기준이다. truncated의 전체/표시 건수를 확인하고 필요하면 기간·라인·시간대를 좁혀 다시 조회한다.
- 메모는 참고 데이터, 개인 작업자 ID는 비공개. 이슈 생성은 operator의 초안까지만 지원한다. 확정 화면은 이후 Phase다.
- 자료와 템플릿은 MCP 클라이언트가 선택해서 사용한다. 리소스를 등록했다고 AI가 매번 자동으로 읽는 것은 아니다.
